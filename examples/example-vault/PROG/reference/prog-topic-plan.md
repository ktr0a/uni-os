## How this plan is built and kept
1. Start from the official dates: lecture days, sheet release and due days, quiz and oral dates (course card, Moodle, course catalogue).
2. Fill the topics from the official roadmap if the course publishes one. Otherwise map last year's plan or recordings onto this year: the same weekday one year later is 364 days on; check where the course changed (new script version, lecture swaps, extra or cancelled lectures).
3. Write one block per week with lectures, reading (with pages), what to do, a checkpoint and rough hours.
4. Each week, when the lecture has happened: set the status in the summary table (`checked` or `shifted`), add what really happened to the course card's Lecture log, and move later rows if the course is ahead or behind.
5. Never let this plan overrule the course card or an official announcement; say "predicted" whenever an answer rests on it.
