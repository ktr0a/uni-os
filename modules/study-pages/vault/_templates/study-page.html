1Growth of functions: O, Ω, Θ

1.1 Why constants do not matter template sample

An algorithm that needs $3n^2$ steps and one that needs $n^2 + 100n$ steps behave alike for large inputs: doubling $n$ roughly quadruples both. An algorithm with $1000n$ steps is slower than both on small inputs, but for large $n$ it is far better. Big-O notation keeps exactly this information, the shape of the growth, and throws away constant factors and the behaviour on small inputs.

  • Picture two runners: one starts far ahead but runs at a constant pace, the other starts behind but keeps speeding up. The second one always wins eventually. "Eventually" is what $n_0$ in the definition means.
  • Constant factors model faster or slower machines. A better machine changes the constant, never the shape.

1.2 The three definitions template sample

Let $f, g:\mathbb{N}\to\mathbb{R}_{\ge 0}$.

  • $f \in O(g)$ if there are constants $c > 0$ and $n_0$ such that $f(n) \le c\cdot g(n)$ for all $n \ge n_0$. ($f$ grows at most as fast as $g$.)
  • $f \in \Omega(g)$ if there are constants $c > 0$ and $n_0$ such that $f(n) \ge c\cdot g(n)$ for all $n \ge n_0$. ($f$ grows at least as fast as $g$.)
  • $f \in \Theta(g)$ if $f \in O(g)$ and $f \in \Omega(g)$. (Same growth up to constant factors.)

Worked example: $3n^2 + 10n \in O(n^2)$. Take $c = 13$ and $n_0 = 1$. For every $n \ge 1$ we have $10n \le 10n^2$, so $3n^2 + 10n \le 3n^2 + 10n^2 = 13n^2$.

Order of the quantifiers: first there exist $c$ and $n_0$, then for all $n \ge n_0$. Writing "for all $n$ there is a $c$" says nothing: every function satisfies it with $c = f(n)/g(n)$.

1.3 The growth hierarchy template sample

From slowest to fastest, each function is in $O$ of the next one but not the other way round:

$$1 \lt \log n \lt \sqrt{n} \lt n \lt n\log n \lt n^2 \lt n^3 \lt 2^n \lt 3^n$$

For products of the form $k^n \cdot n^a \cdot (\log n)^b$ there is a three-step test: compare the exponential bases $k$ first; if they are equal, compare the powers $a$ of $n$; if those are equal too, compare the powers $b$ of the log. The first difference decides. The demo and the quiz below use exactly this test to compute their answers.

Constants in the exponent do matter. $2^{n+1} = 2\cdot 2^n \in O(2^n)$, but $2^{2n} = 4^n \notin O(2^n)$, because $4^n / 2^n = 2^n$ is unbounded. Bases of logarithms do not matter inside $\Theta$: $\log_{10} n = \log_2 n / \log_2 10$.

Growth race: pick two functions

The vertical axis shows $\log_2$ of the value, so $2^n$ is a straight line and polynomials bend. The verdict is computed with the three-step test from 1.3, and the crossover is found by checking every $n$ in the range.

2Counting the steps of loops

2.1 Count exactly first, classify later template sample

To find the running time of a loop, first write down the exact number of times the innermost statement runs, as a sum. Only then simplify it and name the class. Jumping straight to "two nested loops, so $n^2$" is the most common way to get these tasks wrong.

for i = 1..n:
  for j = i..n:
    count += 1

For a fixed $i$ the inner loop runs $n - i + 1$ times, so the total is $\sum_{i=1}^{n}(n-i+1) = n + (n-1) + \dots + 1 = \frac{n(n+1)}{2} \in \Theta(n^2)$.

2.2 Doubling and halving loops template sample

A loop whose counter doubles ($i = 1, 2, 4, 8, \dots$ while $i \le n$) runs once for each power of 2 that is at most $n$: that is $\lfloor \log_2 n \rfloor + 1$ times. Halving loops behave the same way.

  • Doubling outer loop, linear inner loop up to $i$: the inner loop costs $1 + 2 + 4 + \dots + 2^k = 2^{k+1} - 1 \lt 2n$ steps in total. That is $\Theta(n)$, not $\Theta(n \log n)$.
  • Linear outer loop, halving inner loop from $n$: every outer step costs $\lfloor\log_2 n\rfloor + 1$, so the total is $\Theta(n \log n)$.

2.3 Test every closed form on n = 1, 2, 3 template sample

A closed form that is off by one still has the right $\Theta$ class, but it gives a wrong number in a "how many times" task. Before you trust a formula, plug in $n = 1, 2, 3$ and compare with a hand count of the loop.

Classic slip: $\lceil \log_2 n \rceil$ looks like the number of doublings, but for $n = 1$ it gives $0$ while the loop runs once. The correct count is $\lfloor \log_2 n \rfloor + 1$.

Loop counter: run the loop, then test a formula

Formulas may use + − * / ^, brackets, and floor, ceil, sqrt, log2 (log means log2), ln. The real counts come from actually running the loop.

Mistakes this topic invites

  • Reading $f \in O(g)$ as "$f$ is about $g$". It is only an upper bound: $n \in O(n^2)$ is true.
  • Dropping a constant in the exponent: $2^{2n} \notin O(2^n)$.
  • Calling a doubling outer loop with a linear inner loop $\Theta(n\log n)$. It is $\Theta(n)$.
  • Trusting a closed form without testing it on $n = 1, 2, 3$.
  • Swapping the quantifiers in the definition.
Procedure to practise
  1. Write the exact count as a sum, one sum per loop, innermost first.
  2. Evaluate the sum for $n = 1, 2, 3$ and compare with a hand trace of the code.
  3. Simplify to a closed form, keep the leading term, then name the $\Theta$ class.
  4. For "is $f \in O(g)$?": compare exponential base, then power of $n$, then log factors. For a proof, name $c$ and $n_0$ explicitly.
