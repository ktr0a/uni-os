# Sources and links

Where everything lives outside this vault, which source wins, and which documents count as the real source for each course. Agents add a line here whenever they learn a new location (append; say when and how you found it).

**Authority order for course facts:** (1) what the student says now, (2) the official course pages (Moodle course page with its announcements, the course website), (3) the course catalogue, (4) the course cards in this vault (they record what was checked and when), (5) the course-facts skill, (6) predicted plans (topic plans, last year's material), (7) anything else derived. Announcements beat file timestamps; the newest dated fact wins among equals.
